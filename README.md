# Thermodynamics

Interactive thermodynamics teaching materials for ES 305, Embry-Riddle Aeronautical University.

## Contents

- **[Polytropic Compression Lab](index.html)** — an interactive piston-cylinder animation comparing polytropic paths (different values of *n*) that all begin at the same state and are driven to the same final volume, including the n → ∞ constant-volume limit. Defaults match Example 2.1 (Moran et al., *Fundamentals of Engineering Thermodynamics*).
- **[Two Paths, Same States](two-paths.html)** — two piston-cylinders animate between the same start and end states by different routes (constant-V-then-constant-p vs. pV = const), showing that ΔU is fixed by the states alone while work and heat transfer are path-dependent. Defaults match Example 7.
