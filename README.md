# Thermodynamics

Interactive thermodynamics teaching materials developed by **Dr. Nuha Aljuneidi**.

## Live activities

- **[Polytropic Compression Lab](https://nuhaaljuneidi.github.io/thermodynamics/)** — compare polytropic paths that begin at the same state and reach the same final volume, including the constant-volume limit.
- **[Two Paths, Same States](https://nuhaaljuneidi.github.io/thermodynamics/two-paths.html)** — compare two processes between the same states and examine why internal-energy change is fixed while work and heat transfer depend on the path.

## Learning outcomes

After using the activities, students should be able to:

- Distinguish state properties from path-dependent quantities.
- Interpret boundary work on a pressure-volume diagram.
- Explain how the polytropic exponent changes a compression path.
- Check whether calculated heat and work are consistent with the first law.

## Run locally

Open `index.html` in a modern browser. No build step or external software is required.
